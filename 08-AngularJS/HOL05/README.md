# HOL5 – Reactive Forms in Angular

## Objective

Develop a Reactive Enrollment Form using Angular Reactive Forms to implement advanced form handling techniques such as FormBuilder, FormGroup, FormArray, synchronous validation, asynchronous validation, and custom validation.

---

## Topics Covered

- Reactive Forms
- FormBuilder
- FormGroup
- FormControl
- FormArray
- Built-in Validators
- Custom Validator
- Async Validator
- Dynamic Form Controls
- Form Submission
- Patch Value

---

## Features

- Student Name Validation
- Email Validation
- Course ID Validation
- Preferred Semester Selection
- Agree to Terms & Conditions
- Dynamic Skills Section (FormArray)
- Add Skill
- Remove Skill
- Fill Sample Data
- Reset Form
- Submit Form
- Success Alert after Submission

---

## Technologies Used

- Angular 20
- TypeScript
- HTML
- CSS
