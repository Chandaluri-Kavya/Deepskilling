# Hands-On Lab 3 – Directives & Pipes

## Objective

Implement Angular structural directives, attribute directives, custom directives, and custom pipes in the Student Course Portal.

---

## Topics Covered

- Structural Directives
  - *ngIf
  - *ngFor
  - *ngSwitch

- Attribute Directives
  - ngClass
  - ngStyle

- Custom Directive
  - Highlight Directive

- Built-in Pipes
  - uppercase
  - titlecase

- Custom Pipe
  - Credit Label Pipe

---

## Features Implemented

### Task 1 – Structural Directives

- Loading screen using *ngIf
- Course list rendered using *ngFor
- trackBy function implemented
- Grade status displayed using *ngSwitch
- No Courses template implemented using ng-template

---

### Task 2 – Attribute Directives

- Dynamic CSS using ngClass
- Dynamic border color using ngStyle
- Expand card using Show Details button
- Getter used for cleaner ngClass binding

---

### Task 3 – Custom Directive & Pipe

- Custom Highlight Directive
- Hover effect on course cards
- Configurable highlight color
- Custom Credit Label Pipe
- Credits displayed as:
  - 1 Credit
  - 3 Credits
  - No Credits

---

- Final Output showing:

  - Show Details Button
