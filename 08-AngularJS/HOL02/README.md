# HOL2 - Student Course Portal

## Objective
Build the Student Course Portal using Angular components and data binding.

## Concepts Covered
- Components
- Property Binding
- Event Binding
- Two-Way Data Binding
- Interpolation
- Component Communication
- *ngFor Directive

## Features Implemented
- Student Course Portal home page
- Course cards
- Enroll button
- Course search
- Selected Course ID display
- Statistics cards (Courses Available, Enrolled, GPA)
