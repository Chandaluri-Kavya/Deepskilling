# HOL4 - Template-Driven Forms & Validation

## Objective
Implement a Student Enrollment Form using Angular Template-Driven Forms with validation and form submission.

## Topics Covered
- Template-Driven Forms
- FormsModule
- ngForm
- ngModel Two-Way Data Binding
- Built-in Validators (required, minlength, email)
- Validation Error Messages
- Form Submission
- Reset Form

## Features Implemented
- Student Name
- Student Email
- Course ID
- Preferred Semester
- Terms & Conditions Checkbox
- Required field validation
- Minimum length validation
- Email validation
- Validation error messages
- Submit button disabled for invalid form
- Success message after successful submission
- Reset button to clear the form

## Technologies Used
- Angular 20
- TypeScript
- HTML
- CSS

## Output
1. Student Enrollment Form
2. Enrollment Request Submitted Successfully
